## 🐙 What is GitHub?

GitHub is a platform that allows developers and students to store, manage, and share their code and project files using Git repositories.

It also supports collaboration and helps keep track of changes made to projects.

## 🪜 Steps to Create a GitHub Repository

The basic process includes:

1. Create or sign in to a GitHub account.
2. Click **New repository**.
3. Enter a suitable repository name.
4. Add a description for the repository.
5. Select the repository visibility.
6. Create the repository.
7. Upload project files.
8. Commit the changes.

## 📂 Repository Structure

A GitHub repository can contain different types of files, such as:

- Source code
- Documentation
- Images
- Project reports
- README files
- Configuration files
